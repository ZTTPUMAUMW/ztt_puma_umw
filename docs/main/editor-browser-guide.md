# Editing PUMA in your browser

Use your own Sanity account. For practice, open the [development Studio](https://puma-development-s2jrzn3b.sanity.studio/). After the production rollout, bookmark the [live Studio](https://puma-production-s2jrzn3b.sanity.studio/). Check the environment in the title.

1. Open the page under **Website / Strona**. Enter both Polish and English. A page and its entries publish together.
2. For a portrait use **Team → Entries → person**. For a model use **Models → Entries → model**. For the home slider or funder logos use **Home → Cards and lists**. Upload the new picture, add both image descriptions and adjust the crop. A bundled original remains available if you clear its replacement.
3. Open **Preview / Podgląd**, choose PL or EN and allow the new tab. Check the draft on desktop and at phone width. Return to Edit to make corrections and refresh the preview after the draft saves.
4. In **Edit**, click **Publish** once ready. In development this publishes to the sandbox. In the live Studio it publishes the entire page to the website. Open the public page in a fresh private window to verify both languages. To abandon unpublished edits, use **Discard changes** after checking the affected document.
5. To correct a published mistake, edit the field, preview and publish again. Use a previous image from the asset picker if needed.

Projects and publications have their own Entries lists. Recruitment and Collaboration have separate form labels. Site settings contains the public contact details. Navigation and branding contains menus, logos and the social sharing image. The closing buttons on Models are shared with Home. In Repository, expand a vitality parameter to edit scores, captions, pictures, MP4s and posters. Upload a prepared silent MP4 for the same playback experience. Only upload files approved for public access. Team reviewers can view the development website without editing privileges.
